## 🖥️ SETUP INSTRUCTIONS

### Option 1: VLC Media Player (Easiest - All Platforms)

**Windows/Mac/Linux:**
1. Download VLC from https://www.videolan.org/
2. Open VLC → **Media** → **Open Network Stream** (Ctrl+N)
3. Paste this URL or browse to your downloaded `.m3u8` file
4. Click **Play**

**To save as a playlist:**
- **Media** → **Open File** → Select `bashkir_mind_iptv.m3u8`
- **View** → **Playlist** to see all channels organized by group

---

### Option 2: IPTV Smarters Pro (Android/iOS/Smart TV)

1. Download "IPTV Smarters Pro" from your app store
2. Open app → Select **"Load Your Playlist or File/URL"**
3. Choose **"M3U URL"**
4. Enter a name: `Bashkir Mind`
5. Enter the file path or host the playlist online
6. Click **Add User** → Enjoy!

---

### Option 3: TiviMate (Android TV / Fire TV) - RECOMMENDED

1. Install TiviMate from Google Play or sideload
2. **Settings** → **Playlists** → **Add Playlist**
3. Select **"M3U Playlist"**
4. Either:
   - Enter URL (if hosted online)
   - Browse to local file
5. **Settings** → **EPG** → Add: `https://iptvx.one/EPG_LITE` for schedule

---

### Option 4: Kodi (Advanced - All Platforms)

1. Install Kodi from https://kodi.tv/
2. Go to **Add-ons** → **Install from Repository**
3. Select **PVR Clients** → **PVR IPTV Simple Client**
4. **Configure**:
   - **General** → **M3U Play List URL**: Point to your file
   - **EPG Settings** → **XMLTV URL**: `https://iptvx.one/EPG_LITE`
5. Enable the add-on → Restart Kodi
6. Channels appear under **TV**

---

### Option 5: GSE Smart IPTV (iOS/iPadOS)

1. Download from App Store
2. Tap **"+"** to add a playlist
3. Select **"Remote Playlists"** → **"Add M3U URL"**
4. Name: `Bashkir Mind`
5. Enter URL or use local file option

## 🗣️ LANGUAGE LEARNING TIPS

### Bashkir ↔ Tatar Cognates (85% similar!)
| Bashkir | Tatar | Meaning |
|---------|-------|---------|
| һөйләү | сөйләү | to speak |
| яҙыу | язу | to write |
| уҡыу | укый | to read |
| әйтеү | әйтү | to say |

### Kazakh Differences (Kipchak but with unique features):
- More Arabic/Persian loanwords
- Different vowel harmony patterns
- Good for understanding broader Turkic world

### Turkish Connections (Oghuz branch):
- Recognizable vocabulary from common Turkic roots
- Different grammar but similar logic
- Great for understanding Turkic history

## ⚠️ TROUBLESHOOTING

**Channel not loading?**
- Some streams may be geo-restricted to their regions
- Try at different times (some are not 24/7)
- Use a VPN set to Russia/Kazakhstan if needed

**Buffering issues?**
- Lower quality streams marked with "SD" work better on slow connections
- Try during off-peak hours

**No sound/video?**
- Make sure your player supports HLS/M3U8
- Update your media player to the latest version
